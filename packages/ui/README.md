# @react-awesome-query-builder-dev/ui

[![npm](https://img.shields.io/npm/v/@react-awesome-query-builder-dev/ui.svg)](https://www.npmjs.com/package/@react-awesome-query-builder-dev/ui)

This package has core React components like `<Query>` `<Builder>` and CSS, provides config with basic (vanilla) widgets.

## Installation

```
npm i @react-awesome-query-builder-dev/ui --save
```

## Usage

Use `BasicConfig`. 

See [minimal example in readme](https://github.com/ukrbublik/react-awesome-query-builder#usage)
